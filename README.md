# Ailo — Phase 1 starter

Expo / React Native JavaScript prototype with tactile claymorphism styling.

## Run
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npx expo start`.
4. Open in Expo Go or Android emulator.

## Working in this starter
- Add birthday, anniversary, or other occasion
- Store occasions locally using AsyncStorage
- Display next occurrence and two planned call times
- Configure optional custom times and disable the second call
- Delete an occasion

## Not implemented yet
Real phone calls, background scheduling, notifications, AI voice, cloud database, authentication. Calls shown are schedule previews, NOT actual scheduled phone calls.
